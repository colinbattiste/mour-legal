SMS OTP Consent Evidence

Mour App LLC · Public A2P 10DLC documentation · Last updated September 15, 2026 · Contact admin@mourapp.com

For Twilio / carrier reviewers This page is public (no login). It documents how end users opt in to MOUR one-time passcode (OTP) SMS inside the MOUR mobile app. There is no website form opt-in and no keyword text-in opt-in for this campaign.

1. Campaign summary

  • Brand / entity: Mour App LLC
  • Brand website: https://mourapp.com
  • App: MOUR mobile app (com.mour.app)
  • Use case: Transactional one-time passcodes for login / signup authentication only — not marketing or promotional messages
  • Opt-in method: In-app phone verification screen only
  • Message frequency: On-demand / as needed when the user requests a code (not recurring)

2. How consent is collected

End users opt in only inside the MOUR mobile app during login or signup:

  1. The user opens the MOUR app and reaches the phone verification screen.
  2. The user voluntarily enters their own mobile phone number.
  3. The screen displays the required SMS disclosures (OTP-only, on-demand frequency, message and data rates, HELP/STOP, consent not a condition of purchase) plus links to the Privacy Policy and Terms of Service.
  4. The user taps Send code (or Continue) to request a verification text. That tap is the affirmative opt-in.
  5. MOUR then sends a single transactional OTP SMS to the number the user entered.

Consent is collected specifically for this OTP campaign. Numbers are not obtained from purchased or shared lead lists. Consent is not a condition of purchase.

3. Required disclosures shown before Send code

The in-app phone verification screen shows this disclosure text (or substantively identical language) before the user can request an OTP:

By tapping Send code, you agree to receive a one-time MOUR authentication SMS to verify your mobile number. Messages are transactional OTPs only (not marketing). Message frequency: on-demand / as needed when you request a code. Message and data rates may apply. Reply HELP for help; reply STOP to opt out. Consent is not a condition of purchase. Privacy Policy and Terms of Service apply.
